# idea-ai
# 🧠 ایده AI - دستیار هوش مصنوعی پیشرفته

پروژه دستیار هوش مصنوعی با رابط کاربری مدرن و قابلیت‌های پیشرفته

## ✨ ویژگی‌ها

- 💬 چت هوشمند با چندین مدل AI
- 🎤 تبدیل صوت به متن و متن به صوت
- 📊 تحلیل متن و استخراج اطلاعات
- 🎨 رابط کاربری واکنش‌گرا و مدرن
- 🌙 سیستم تم‌بندی پویا
- 🔄 پشتیبانی از زبان فارسی و انگلیسی
- 🐳 پشتیبانی از Docker

## 🛠️ تکنولوژی‌ها

### Backend
- **FastAPI** - فریمورک وب مدرن
- **SQLAlchemy** - ORM پایگاه داده
- **JWT** - احراز هویت
- **OpenAI/Anthropic** - مدل‌های هوش مصنوعی

### Frontend
- **React** - کتابخانه رابط کاربری
- **Vite** - ابزار build
- **Tailwind CSS** - فریمورک CSS
- **Axios** - کلاینت HTTP

## 🚀 راه‌اندازی

### پیش‌نیازها
- Python 3.11+
- Node.js 18+
- Docker (اختیاری)
